# Configuration Directory

This directory contains all configuration files for Finovate Audit Nexus AI.

## Files

- `settings.json` - Main application settings
- `.env` - Environment variables (create from .env.example)

## Setup Instructions

1. Copy `.env.example` to `.env` in the project root
2. Edit `settings.json` to customize your configuration
3. Update database credentials, API keys, and security settings

## Security Notice

⚠️ **Important**: Never commit `.env` files or sensitive configuration to version control!
