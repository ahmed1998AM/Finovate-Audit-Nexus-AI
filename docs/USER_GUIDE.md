# دليل المستخدم - Finovate Audit Nexus AI

## بدء الاستخدام

### تشغيل التطبيق
```bash
# تشغيل الخادم وسطح المكتب (الوضع الموصى به)
python main.py --all

# تشغيل سطح المكتب فقط
python main.py --desktop

# تشغيل الخادم فقط
python main.py --api
```

### تسجيل الدخول
عند أول تشغيل، يتم إنشاء مستخدمين افتراضيين:
- **admin** / كلمة المرور في ملف `.initial_passwords`
- **auditor1** / كلمة المرور في ملف `.initial_passwords`

> يُرجى تغيير كلمة المرور بعد أول تسجيل دخول.

## واجهة المستخدم

### الشريط الجانبي (Sidebar)
يحتوي على 11 صفحة رئيسية:

1. **لوحة القيادة** - مؤشرات الأداء الرئيسية
2. **القيادة التنفيذية** - KPIs + توصيات الإدارة العليا + ملخص تنفيذي
3. **التحليلات** - تحليلات مالية سريعة
4. **وكلاء AI** - تشغيل وإدارة 22 وكيل ذكي
5. **التقارير** - عرض وإنشاء وتصدير التقارير (PDF/HTML/JSON/Excel)
6. **إدارة AI** - إعداد مزودي LLM (OpenAI, Anthropic, Gemini, Groq, Ollama)
7. **الموصلات** - إدارة 15 موصل ERP (SAP, Oracle, QuickBooks, Xero...)
8. **مشاريع التدقيق** - إنشاء وإدارة مشاريع المراجعة
9. **كشف الاحتيال** - تنبيهات وتحقيقات الاحتيال
10. **الامتثال** - معايير وتقارير الامتثال (IFRS, GAAP, SOX)
11. **الإعدادات** - إعدادات التطبيق والمظهر

### سير العمل الأساسي
1. **افتح بيانات** - استيراد ملف Excel/CSV/PDF
2. **تشغيل مراجعة** - تحليل البيانات عبر وكيل AI
3. **عرض النتائج** - الاطلاع على الملاحظات والتوصيات
4. **إنشاء تقرير** - تصدير التقرير التنفيذي

## استكشاف الأخطاء وإصلاحها

**المشكلة**: التطبيق لا يفتح
- تأكد من تثبيت Python 3.11+
- شغّل `pip install -r requirements.txt`

**المشكلة**: فشل الاتصال بالخادم
- تأكد من تشغيل `python main.py --api`
- افحص الإعدادات > عام > رابط API

**المشكلة**: فشل الاختبارات
- شغّل `python main.py --test` لرؤية التفاصيل
- تأكد من تثبيت `pytest` و `pytest-asyncio`
